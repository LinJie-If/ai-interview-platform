
## 发给 ChatGPT 的项目总结

我在学习一个开源项目，想用它做项目复刻练习。请你基于下面的信息，帮我把每天的任务进一步细化，做到可执行、可落地、适合新手推进。

### 1. 项目来源和目标
我现在在学习一个开源项目，它是一个“AI 智能面试平台”。  
我不是直接改它的源码，而是要**在我自己的新项目里重新复刻一个 Vue 版本**，把它当作学习项目。

我的目标不是 100% 像原项目，而是：
- 理解这个项目的完整架构
- 自己实现一个可运行的版本
- 通过复刻来学习 Spring Boot、Spring AI、PostgreSQL/pgvector、Redis、对象存储、RAG、前后端联调这些能力

### 2. 原项目大致功能
这个项目主要有 3 个业务模块：

1. 简历分析
- 上传简历文件
- 保存文件
- 解析简历文本
- 用大模型分析简历
- 输出总分、摘要、建议
- 展示简历列表和详情

2. 模拟面试
- 根据简历生成面试题
- 用户逐题作答
- 保存答题过程
- 生成面试报告
- 查看面试历史

3. 知识库 / RAG
- 上传知识库文档
- 解析文档
- 文本切分
- 向量化
- 检索增强问答
- 可选 SSE 流式输出

### 3. 原项目的技术栈
原项目的前端是 React，不是 Vue。  
原项目的后端是 Spring Boot。

原项目大致技术栈：
- 前端：React + TypeScript + Vite
- 后端：Spring Boot
- AI：Spring AI
- 数据库：PostgreSQL + pgvector
- 缓存 / 异步：Redis
- 文件存储：S3-compatible（本地开发可用 MinIO，也可理解为 RustFS 一类对象存储）
- 文档解析：Apache Tika

### 4. 我要复刻的技术栈
我的复刻项目计划用：
- 前端：Vue3 + TypeScript + Vite + Vue Router + Pinia + Axios
- 后端：Spring Boot
- 数据库：PostgreSQL + pgvector
- Redis：后期用于异步任务
- 对象存储：本地开发先用 MinIO 或其他 S3-compatible 方案
- AI：Spring AI
- 文档解析：Apache Tika

也就是说：
- 只把前端从 React 换成 Vue3
- 后端和基础设施尽量沿用原项目思路

### 5. 这个项目最核心的工程链路
这个项目最值得学习的不是 UI，而是这条工程链路：

- 用户上传文件
- 后端保存文件元数据
- 文件存到对象存储
- 后端解析文本
- AI 生成结果
- 数据库存业务结果
- Redis 负责缓存和异步任务
- 前端轮询或流式展示状态和内容

### 6. 我现在的复刻策略
我打算按阶段复刻，而不是一次性做完所有功能。

第一阶段：
- 简历分析
- 模拟面试
- 先不做知识库/RAG
- 先不做 Redis 异步
- 先不做 SSE
- 先不做 PDF 导出
- 先不做限流

第二阶段：
- Redis Stream 异步化
- 状态流转
- 错误处理完善

第三阶段：
- 知识库管理
- RAG 问答
- pgvector
- 可选 SSE
